1. JavaScript dan kegunaannya
JavaScript adalah bahasa pemrograman yang digunakan untuk membuat halaman web menjadi interaktif. Contohnya, menampilkan pesan, memvalidasi input pada form, dan merespons ketika pengguna menekan tombol.

2. jQuery dan kegunaannya
jQuery adalah library JavaScript yang mempermudah penulisan kode untuk mengatur elemen HTML, mengubah tampilan CSS, menangani klik tombol, serta menyembunyikan dan menampilkan elemen pada halaman web.

3. Perbedaan JavaScript dan jQuery
JavaScript merupakan bahasa pemrograman, sedangkan jQuery adalah library yang dibuat menggunakan JavaScript. JavaScript dapat digunakan secara langsung tanpa library tambahan, sementara jQuery memerlukan library jQuery. jQuery menyediakan sintaks yang lebih singkat untuk berbagai tugas, seperti memilih elemen HTML dan menangani event.
